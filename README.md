# Sky Hop v3

Статическая пиксельная аркада для Telegram Mini Apps и обычного браузера.

**Запуск:** открой index.html. Никакой установки и сервера не требуется.

**Публикация:** загрузи HTML/CSS/JS в корень публичного репозитория, включи Settings → Pages → main → / (root).

**Telegram:** задай опубликованный HTTPS-адрес через @BotFather → /setmenubutton.

[Подробная инструкция с нуля](НАЧНИ-ЗДЕСЬ.md) · [Результаты проверок](ПРОВЕРКА.md)

Монеты и рекорд сохраняются на текущем устройстве через Telegram DeviceStorage или localStorage. Между устройствами прогресс не переносится. Токен бота не используется.
