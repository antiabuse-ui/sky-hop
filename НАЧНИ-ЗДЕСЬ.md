# Sky Hop v3 — без сервера и платных сервисов

Готовая статическая аркада для обычного браузера и Telegram Mini Apps. Никаких баз данных, API-ключей, регистрации, собственного сервера или постоянно работающей программы бота не требуется. Все игровые ресурсы, кроме необязательного шрифта и официального Telegram SDK, находятся в папке проекта.

## Быстрый запуск

1. Распакуй архив.
2. Открой `index.html` двойным щелчком.
3. Дождись загрузки сохранения и нажми **НАЧАТЬ ПОЛЁТ**.
4. Управляй одним касанием, кликом по полю или пробелом. Кнопка паузы находится отдельно над полем слева; на компьютере работает Escape.

Начинать локально можно без Node.js, Python, терминала и установки пакетов. Для проверки именно в Telegram сначала опубликуй файлы на HTTPS — порядок ниже.

## Что изменено

- **Главное меню:** сначала загружаются монеты и рекорд, затем включается кнопка начала. На фоне движутся облака, птица парит и машет крыльями. Полёт не начинается автоматически.
- **Пауза:** отдельная кнопка и Escape. Замораживаются физика, трубы, монеты, частицы, фон и таймер уведомлений. Продолжение сохраняет координаты, скорость, счёт и защиту; лишний взмах при возобновлении не добавляется.
- **Автопауза:** скрытие страницы, потеря фокуса, сворачивание Telegram. Возвращение в приложение не запускает полёт само: нажми «Продолжить игру».
- **Выход в меню:** завершает попытку, сохраняет накопленные монеты и текущий рекорд. Новая игра начинается с нуля очков.
- **Птица:** восемь кадров крыльев, плавный наклон по вертикальной скорости. При подъёме птица выравнивается, при падении наклоняется клювом вниз. Спрайты кэшируются, геометрия столкновений остаётся прежней.
- **Достижения:** каждые 100 очков появляется уведомление на 1,8 секунды, без отдельных условий для 100/200/300. «НОВЫЙ РЕКОРД!» появляется один раз за попытку, сопровождается звёздочками. Уведомления стоят в отдельной полосе и не закрывают препятствия.
- **Фразы:** прежние шесть фраз, включая ненормативную лексику, сохранены. Fisher–Yates shuffle bag показывает весь набор до повторов и исключает последние две фразы предыдущего набора из начала следующего.
- **Сохранены:** пиксельные трубы и земля, бесконечный параллакс-фон, монеты и эффекты сбора, анимация смерти, рекорд, возрождение за ровно 20 игровых монет и 2 секунды защиты после возрождения.
- **Телефоны:** Pointer Events для касания, safe area, динамическая высота окна, масштабирование поля без изменения физики, отсутствие прокрутки страницы и лишнего взмаха от кнопок. Длинная панель проигрыша прокручивается внутри себя на маленьких экранах. Основная ориентация — вертикальная; в горизонтальной поле уменьшается. Если Telegram поддерживает функцию, справа вверху доступна кнопка полноэкранного режима.

## Где сохраняется прогресс

Модуль `storage.js` хранит один локальный объект: баланс монет, личный рекорд, версию формата и номер изменения. Логика игры не запрашивает и не хранит Telegram ID или другие данные пользователя.

1. В Telegram с поддержкой Bot API 9.0+ используется **Telegram.WebApp.DeviceStorage**. Telegram сам изолирует такое хранилище по мини-приложению и текущему пользователю на устройстве. Код игры не узнаёт ID.
2. Если DeviceStorage не поддерживается или не отвечает при чтении, используется **localStorage** браузера/встроенного окна Telegram.
3. Если локальная запись запрещена, игра продолжает работать в памяти и показывает предупреждение, что прогресс может пропасть после закрытия. При ошибке записи DeviceStorage автоматическое переключение между хранилищами во время попытки не выполняется: это предотвращает смешивание несовпадающих балансов. Появляется предупреждение, дальнейшие изменения остаются в памяти до закрытия.

Чтение и запись DeviceStorage асинхронные. Записи сериализуются, чтобы получение монеты и покупка возрождения не перезаписывали друг друга. При получении монет и обновлении рекорда прогресс сохраняется сразу, не только после смерти. Возрождение блокирует повторное нажатие до завершения операции и может списать ровно 20 монет один раз для текущей смерти. При ошибке сохранения монеты всё равно списываются в текущей игровой сессии: повторное нажатие не делает возрождение бесплатным.

В браузере используется ключ **sky-hop-progress-v3**. Старые браузерные сохранения из sky-hop-wallet-v2 и sky-hop-best переносятся автоматически. В новый DeviceStorage старый браузерный баланс намеренно не импортируется, поскольку приложение не должно определять аккаунт. Серверные балансы v2 больше не читаются: сервер и авторизация удалены из этой сборки.

### Ограничения локальных сохранений

- Переноса между телефоном и компьютером, разными браузерами или устройствами нет. CloudStorage не используется.
- Очистка данных, удаление приложения, приватный режим или ограничения браузера могут удалить прогресс или запретить сохранение.
- При fallback на localStorage данные относятся к браузеру и домену, а не к подтверждённому Telegram-аккаунту. На общем устройстве они могут быть общими для нескольких аккаунтов. Копии игры на одном домене могут использовать один ключ сохранения.
- Переезд на другой домен может открыть другое локальное сохранение. DeviceStorage и localStorage не синхронизируются.
- Не открывай одну игру одновременно в нескольких вкладках: последнее сохранение может перезаписать результат другой вкладки. Это локальная одиночная игра, без общей базы и соревновательной защиты от изменения файлов/баланса.
- Если закрыть приложение до завершения асинхронной записи, последнее изменение может не сохраниться. Предупреждения о сохранении отображаются внизу экрана.

## Бесплатная публикация на GitHub Pages с нуля

Свой сервер и домен покупать не нужно. GitHub Pages предоставляет HTTPS на github.io; на бесплатном плане для этого способа используется публичный репозиторий.

1. Открой https://github.com и создай аккаунт, если его нет. Войди.
2. Открой https://github.com/new.
3. В поле Repository name введи **sky-hop**. Выбери **Public**, включи **Add README**, нажми **Create repository**.
4. В репозитории выбери **Add file → Upload files**.
5. Из распакованной папки загрузи **содержимое**, а не внешнюю папку или ZIP. Для игры нужны:
   - index.html
   - style.css
   - game.js
   - storage.js
   - wallet.js
   - rules.js
   - telegram.js
   - .nojekyll — необязательный пустой файл, отключающий обработку Jekyll.
6. Проверь, что index.html расположен прямо в корне репозитория. Нажми **Commit changes**, сохрани в ветку main.
7. Открой **Settings → Pages**.
8. В **Build and deployment → Source** выбери **Deploy from a branch**.
9. Выбери ветку **main**, папку **/ (root)**, нажми **Save**.
10. Дождись завершения публикации. Страница Pages покажет фактический адрес вида **https://ВАШ-ЛОГИН.github.io/sky-hop/**. Это шаблон, а не уже опубликованная ссылка. Обычно публикация занимает несколько минут; состояние видно во вкладке Actions.
11. Открой выданный HTTPS-адрес в браузере и проверь игру. Стандартные github.io-адреса поддерживают HTTPS. Если доступно, включи **Enforce HTTPS** в Pages.

Ни Node.js, ни Python после публикации не запускаются. Загружать старые server.cjs/api.cjs, базу, .env, Docker и файлы из sky-hop-v2 не нужно. Эта новая папка уже содержит только статический проект и документацию/тесты. Секретов в ней нет.

**Обновления:** загружай изменённые файлы в тот же репозиторий, сохраняй изменения и дожидайся новой публикации. Файлы в корне связаны относительными адресами и работают в подпапке /sky-hop/. Не удаляй исходный адрес без необходимости — это помогает сохранить доступ к локальному прогрессу.

**Если Pages показывает 404:** проверь имя index.html, ветку main, папку root и завершение публикации. Открывай полный URL со /sky-hop/.

## Подключение игры к Telegram

1. Открой официальный **@BotFather**: https://t.me/BotFather.
2. Если своего бота ещё нет, отправь `/newbot`.
3. Введи название, затем свободное имя пользователя, заканчивающееся на bot.
4. BotFather выдаст токен. **Для этой игры токен не используется.** Не добавляй его в GitHub, код или чат.
5. Отправь `/setmenubutton`, выбери своего бота. Альтернативный путь: `/mybots` → бот → **Bot Settings → Menu Button**.
6. По вопросам BotFather укажи **фактический HTTPS-адрес** с GitHub Pages и надпись **Играть**.
7. Открой личный чат с ботом, нажми **Start**, затем кнопку **Играть** рядом с полем ввода. Игра откроется внутри Telegram.
8. Проверь касание, паузу, монеты и повторное открытие на Android/iOS. Бот при этом не обязан отвечать сообщением на /start — отдельной программы, обрабатывающей сообщения, здесь нет.

Опционально настрой **Main Mini App** в BotFather на тот же URL: появится кнопка запуска в профиле и станет доступна ссылка **https://t.me/ИМЯ_БОТА?startapp**. Одной настройки Menu Button недостаточно для этой ссылки. Games API и /newgame для этой версии не нужны.

Если игра открывается в обычном браузере, но не в Telegram: проверь публичный HTTPS-адрес, запуск именно через кнопку Mini App и актуальность клиента Telegram. Если полноэкранный режим недоступен, игра продолжает работать в обычном окне Mini App.

## Проверка на своём устройстве

1. При открытии виден главный экран; баланс и рекорд появляются после чтения сохранения.
2. «НАЧАТЬ ПОЛЁТ» начинает игру. Пробел/клик/касание подбрасывает птицу.
3. Кнопка паузы и Escape останавливают всё; продолжение не добавляет взмах и не сбрасывает состояние.
4. «Меню» завершает попытку, сохраняя монеты и рекорд.
5. Монеты собираются один раз. При 20+ можно купить возрождение, счёт сохраняется.
6. После перезагрузки баланс и рекорд восстановлены на этом же устройстве в том же хранилище.
7. Сворачивание Telegram включает паузу; возврат не запускает полёт автоматически.
8. После шести проигрышей использованы все шесть разных фраз. При переходе к следующему набору последние две не повторяются в начале нового.
9. Уведомления о новом рекорде и сотнях очков появляются над игровым полем, не закрывая птицу.
10. На маленьком экране все кнопки доступны: длинную панель можно прокрутить внутри неё.

Для ускоренной проверки **обычного браузера** открой Console в инструментах разработчика, выполни и перезагрузи:

```javascript
localStorage.setItem('sky-hop-progress-v3', JSON.stringify({version:3, balance:25, best:0, revision:0}));
location.reload();
```

Это меняет только browser/localStorage, не DeviceStorage Telegram. Настоящий токен не нужен. Для проверки сотен очков и защиты от повторов уже включены автоматические тесты; игрового «чит-режима» в публичном интерфейсе нет.

## Автоматические проверки

Необязательный шаг для разработчика: с установленным Node.js выполни из этой папки:

```text
node --test tests.cjs
```

Для игры и публикации Node.js не требуется. Tests.cjs использует стандартные библиотеки Node, без установки зависимостей. Результаты проверки в текущей среде находятся в ПРОВЕРКА.md.

## Структура и изменения

- **index.html** — главный экран, пауза, баланс, меню, полоса уведомлений, полноэкранная кнопка.
- **style.css** — адаптивная компоновка, safe area, пиксельные панели, анимации и сенсорное управление.
- **game.js** — сохранённые физика и пиксельные ресурсы v2, новые состояния меню/паузы, наклон и кэш кадров, уведомления.
- **storage.js** — новый модуль асинхронного локального сохранения.
- **wallet.js** — прежний интерфейс монет/возрождения переведён на локальный модуль.
- **rules.js** — shuffle bag и универсальные пороги достижений.
- **telegram.js** — только возможности интерфейса Telegram, события видимости, safe area и fullscreen. ID, initData и авторизацию не читает.
- **.nojekyll**, **README.md**, **НАЧНИ-ЗДЕСЬ.md**, **ПРОВЕРКА.md**, **tests.cjs** — публикация, инструкции и проверки.

Физические параметры остались в начале game.js: GAP — размер прохода, SPEED — скорость труб, GRAVITY — падение, FLAP — сила взмаха. Фиксированный шаг физики 1/120 секунды, отрисовка через requestAnimationFrame с deltaTime. Цель — плавные 60 FPS; фактическая частота зависит от устройства и режима энергосбережения.

Шрифт Press Start 2P необязателен и загружается с Google Fonts; без доступа к нему используется читаемый моноширинный шрифт. Изображения и текстуры не загружаются с внешних серверов.
